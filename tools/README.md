# Research tools

For the final report, start with the [sampling and optimisation guide](../research/README.md). The [file guide](../docs/FILE_GUIDE.md#research-and-plotting-programs) explains every script here.

Main chain: measured search → strict non-regression attempt → task-prioritised t027 search → held-out validation → dense Chapter 5 characterisation. Path recovery is a separate post-hoc investigation. `final_geometry_comparison.py` is a later supplementary comparison and did not replace t027.

Earlier Stage 2–5A, broad-hardware, regional and symmetry scripts remain as dependencies and development evidence. Their original domain/settings should not be conflated with the final measured-hardware study. Full research scripts use fixed output paths; follow the reproduction guide in a separate copy.
